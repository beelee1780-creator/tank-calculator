Save this app to your phone

Use the web link, not Google Drive. Opening the file from Drive or Files is why it was not saving, especially on iPhone.

Web link: https://beelee1780-creator.github.io/tank-calculator/

iPhone: Open the link in Safari (not the Drive or Files preview). Tap the Share button, then Add to Home Screen. Open it from the Home Screen after that. It will work offline and keep your gauges on this phone.

Android: Open the link in Chrome, tap the menu (three dots), then Add to Home screen or Install app.

If you ever need to move the data, use Backup below: download or copy a backup, then import it on the other phone.
